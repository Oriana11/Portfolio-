# My Portfolio Website

A clean, responsive portfolio website showcasing my software development projects and professional background.

![Portfolio Preview](img/portfolio-preview.png)

## Overview

This portfolio website serves as a comprehensive showcase of my work as a software developer. It features a modern, user-friendly design with sections for personal introduction, project showcase, and professional contacts.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop and mobile devices
- **Project Showcase**: Interactive cards displaying my key projects with:
  - Project thumbnails
  - Brief descriptions
  - Direct links to GitHub repositories
- **Professional Introduction**: Concise overview of my educational background and technical expertise
- **Contact Section**: Easy access to professional profiles and contact information
- **Clean Navigation**: Intuitive top navigation with quick access to GitHub and LinkedIn profiles
